# 🎮 Tic-Tac-Toe Game

A simple, interactive, and responsive **Tic-Tac-Toe** game built for two players. Take turns placing **X** and **O** on a 3×3 game board and try to get three symbols in a row before your opponent.

🌐 **Live Demo:** https://tic-tac-toe-tawny-zeta.vercel.app/

---

## 📌 Description

Tic-Tac-Toe is a classic two-player strategy game played on a 3×3 grid.

Players take turns marking an empty cell with their respective symbol:

* **Player 1 → X**
* **Player 2 → O**

The player who successfully places three of their symbols in a horizontal, vertical, or diagonal line wins the game.

If all cells are filled without a winner, the game ends in a **draw**.

## 🕹️ How to Play

1. Open the game.
2. Player 1 starts with **X**.
3. Player 2 plays with **O**.
4. Players take turns selecting an empty cell.
5. Get **three symbols in a row** to win.
6. If the entire board is filled without a winner, the game is a draw.
7. Use **Reset Game** to start a new match.

---

## 🏆 Winning Conditions

A player wins when they have three matching symbols in any of these patterns:

```text
X | X | X
--+---+--
O | O | 
--+---+--
  |   |
```

### Possible winning combinations

* Horizontal
* Vertical
* Diagonal
